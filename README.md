# Оазис — прототип

Roguelite-колода с выкладкой клеток: тяните воду каналами от источников, сажайте сад из карт и переживите бурю.

- Играть: `index.html` (открывается в браузере, без установки и регистрации)
- Ванпейджер: `onepager.html`
- Технологии: HTML, CSS, JavaScript без движка и сборки; арт — SVG, нарисованный кодом
- AI: Claude Code — механики, код, SVG-арт, бот-автоигрок для проверки баланса

## Содержание

3 региона × 5 оазисов, 17 карт, 13 типов клеток, 10 реликвий, мета-прогресс. Одна партия — 30–45 минут.

## Проверка баланса

`tools/bot.js` — жадный автоигрок. Подключить на странице игры (DevTools → Console), затем `botRuns(20)` вернёт результаты походов по уровням.
